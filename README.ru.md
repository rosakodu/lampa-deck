# lampa-deck

Плагин для Decky Loader на Steam Deck, который запускает полностью локальный экземпляр каталога и плеера **Lampa**, TorrServer-gst и кастомный транскодер **WebM VP8 + Opus** для бесшовного воспроизведения торрентов во встроенном плеере Lampa в Steam Big Picture (Игровом режиме).

![Screenshot](assets/screenshot.png)

## 📋 Возможности

- **Локальный Lampa**: Раздает статические файлы Lampa на порту 8300.
- **Встроенный TorrServer**: Автоматически скачивает стабильный TorrServer-gst для локального стриминга торрентов на порту 8090.
- **Транскодирование WebM VP8 + Opus**: Фоновый движок транскодирования на базе FFmpeg преобразует неподдерживаемые в SteamOS форматы видео (HEVC/H.265, AV1, H.264) и аудио (AC-3, DTS, AAC) в полностью свободный формат WebM (VP8 + Opus) на лету. Это позволяет воспроизводить любые фильмы прямо во встроенном плеере Lampa без ошибок звука и изображения.
- **Продолжить просмотр**: Кнопка для запуска Lampa на последней открытой странице/вкладке.
- **Панель управления**: Быстрый перезапуск TorrServer и кнопка очистки кэша (очищает базу данных TorrServer для освобождения места).
- **Локализация**: Полный перевод интерфейса на английский, русский, китайский (упрощенный и традиционный), арабский, персидский и турецкий языки.
- **Чистая установка (Комплаенс)**: Плагин поставляется как чистое ПО без предустановленных трекеров, парсеров или внешних скриптов. Все источники настраиваются пользователем самостоятельно.

## ⚙️ Настройка Lampa (Что нужно прописать)

Lampa является модульной платформой и для поиска и воспроизведения контента требует настройки источников. Следуйте этой простой инструкции:

### 1. Подключение к локальному TorrServer
Встроенный TorrServer запускается автоматически вместе с плагином на вашем Steam Deck. Чтобы Lampa направляла торренты в него:
1. В Lampa перейдите в **Настройки** (значок шестерёнки в левом меню) ➔ **TorrServer**.
2. В поле **Основная ссылка** укажите:
   ```text
   http://127.0.0.1:8090
   ```
3. Убедитесь, что переключатель **Использовать ссылку** установлен в положение **Одна**.

### 2. Настройка парсера (Поиск торрент-раздач)
Для поиска раздач по трекерам:
1. В **Настройках** Lampa выберите раздел **Парсер**.
2. Включите пункт **Использовать парсер**: установите **Да**.
3. Выберите **Тип парсера**: **Jackett**.
4. В поле **Ссылка на Jackett** укажите адрес публичного парсера:
   ```text
   https://jac.red
   ```
   *(Либо адрес вашего собственного локального сервера Jackett / Prowlarr / JacRed)*.

### 3. Добавление плагинов (TMDB, Онлайн-балансеры, CUB)
Плагины добавляют описания, постеры и возможность онлайн-просмотра без скачивания торрентов:
1. В **Настройках** Lampa откройте раздел **Плагины**.
2. Нажмите **Добавить плагин** и введите ссылку на нужный плагин:
   * **TMDB Прокси** (исправление постеров, описаний и рейтингов без VPN):
     ```text
     https://plugin.rootu.top/tmdb.js
     ```
   * **CUB / etor** (отображение источников раздач и расширенной информации):
     ```text
     http://cub.red/plugin/etor
     ```
   * **Онлайн-просмотр** (просмотр через онлайн-балансеры без использования торрентов):
     ```text
     https://nb557.github.io/plugins/online_mod.js
     ```
3. После добавления адресов перезапустите Lampa для загрузки плагинов.
